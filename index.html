    Tentang proyek ini

    Aplikasi ini dibuat untuk Tugas Pertemuan 6 (Pengembangan Aplikasi Web). Berikut ringkasan alat yang dipakai dan alasannya.

    01

    Git & GitHub

    Git mencatat riwayat perubahan kode sebagai commit. Fitur yang dipakai: branch untuk mengerjakan fitur terpisah dari main, merge untuk menggabungkannya, penyelesaian merge conflict saat dua branch mengubah baris yang sama, serta push/pull untuk sinkron dengan GitHub. Pull Request dipakai agar perubahan bisa ditinjau sebelum masuk ke main. File .gitignore menjaga node_modules, dist, dan .env tidak ikut terunggah.

    02

    npm

    npm adalah pengelola paket Node.js. Semua paket dan perintah proyek tercatat di package.json. dependencies dibutuhkan saat aplikasi berjalan, sedangkan devDependencies hanya untuk pengembangan (di proyek ini: TypeScript dan Vite). Versi memakai semantic versioning MAJOR.MINOR.PATCH; tanda ^5.4.10 berarti boleh naik ke 5.x.x terbaru tanpa berpindah ke versi mayor 6. Perintah utama: npm install, npm run dev, npm run build.

    03

    TypeScript

    TypeScript adalah JavaScript dengan sistem tipe, sehingga kesalahan seperti salah nama properti terdeteksi sebelum kode dijalankan. Contoh yang dipakai di kode: tipe primitif (string, number, boolean), array (Task[]), interface (Task), type alias dan union type (TaskStatus), serta generics (loadFromStorage<T>, findById<T>).

    04

    Vite

    Vite adalah build tool. Saat pengembangan (npm run dev) ia menjalankan server lokal dengan pembaruan instan. Saat npm run build ia menggabungkan dan memperkecil kode menjadi folder dist/ yang siap diunggah ke website.

    05

    Environment variables

    Konfigurasi disimpan di .env dan dibaca lewat import.meta.env. Hanya variabel berawalan VITE_ yang dikirim ke browser, jadi nama aplikasi, versi, dan nama pembuat aman dipakai. Password dan API key tidak boleh ditaruh di sini karena isi bundle bisa dibaca siapa pun. .env masuk .gitignore, sedangkan .env.example diunggah sebagai contoh.

    06

    Compiler, transpiler, bundler

    Compiler menerjemahkan kode ke bentuk lain sekaligus memeriksanya (tsc memeriksa tipe). Transpiler mengubah kode ke bahasa sejenis di level yang sama, misalnya TypeScript ke JavaScript (dikerjakan esbuild di Vite). Bundler menggabungkan banyak modul dan aset menjadi sedikit file yang efisien untuk browser (Rollup di vite build).
